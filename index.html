ABOUT LYRx

From a music-player idea to a working product.

LYRx is an independently developed desktop music platform focused on building a modern, organized and enjoyable listening experience.

The application uses a modular architecture with separate UI screens, services, provider integrations, persistence, authentication and media workflows rather than a single monolithic interface.

The v1.0.0 release is the first production Windows build and includes the core experience showcased on this page.
